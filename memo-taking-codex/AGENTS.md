# 메모 앱 실습 지침

- 상세 구현 기준은 `SPEC.md`를 읽고 따릅니다.
- 개발 서버는 `uvicorn`으로 실행합니다. Python 패키지는 `pip` 또는 `uv`로 설치합니다.
- 요구사항 정리 단계에서는 코드를 작성하지 않고 결정할 항목을 대화로 확인합니다.
- 계획에는 pytest 파일 경로·함수명, 정상·경계값·실패 사례의 입력과 기대 응답, 실행 명령을 포함합니다.
- 구현을 요청받으면 계획한 테스트를 작성·실행하고, 실패 원인을 수정해 재실행합니다. 실행하지 못한 검사는 통과했다고 보고하지 않습니다.
- 답변은 간결하게 작성합니다.
- 새 Git 작업은 `main`에서 `codex/` 브랜치로 시작합니다. 커밋은 Conventional Commits를 사용하고, 변경은 PR로 검토합니다.
