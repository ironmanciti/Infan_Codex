# 인프런 코덱스 실습 소스

이 저장소에는 코덱스 강의에서 사용하는 두 개의 독립 실습 프로젝트가 있습니다.

| 폴더 | 용도 |
| --- | --- |
| `memo-taking-codex/` | 요구사항을 정리하고 메모 앱을 단계별로 구현하는 실습 |
| `jobportal-codex/` | 완성된 채용 포털을 탐색하고 의도된 결함을 분석·수정하는 실습 |

각 실습은 해당 폴더를 작업 디렉터리로 열어 진행하세요. 프로젝트별 코덱스 지침은 각 폴더의 `AGENTS.md`에 있습니다. 메모 앱 실습의 시작 문장은 `SPEC_Prompt.txt`, 상세 사양은 `memo-taking-codex/SPEC.md`를 참고하세요.

채용 포털에는 프로젝트 스킬(`.agents/skills/`), 검토용 하위 에이전트와 훅(`.codex/`) 예제가 포함되어 있습니다. 프로젝트 훅은 신뢰한 프로젝트에서만 로드되므로, 사용 중인 코덱스 환경의 설정을 확인한 뒤 실습하세요.
